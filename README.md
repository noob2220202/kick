# A 그룹 필수 가입 봇

A 그룹에 없는 사람은 B 채널에서 킥 (차단 아님, 다시 입장 가능)

## 동작
- **B 입장 요청**: A 가입자면 바로 승인. 아니면 개인 메시지로 A 링크 + [입장완료] 버튼 전송 → 누르면 A 가입 확인 후 승인
- **A 탈퇴**: B 에서 바로 킥
- **B 입장**: A 미가입자면 킥 (다른 관리자가 승인했을 때 등)
- **정기 정리**: `SWEEP_INTERVAL_HOURS` 마다 봇이 아는 B 회원 전체 재검사 (봇이 꺼져 있던 동안 놓친 탈퇴 처리)

## 설치 / 실행
```bash
pip install --user -r requirements.txt
cp config.example.py config.py   # 값 채우기
nohup python3 bot.py > bot.log 2>&1 &
```

## 준비
1. 봇을 **A, B 양쪽 채널 관리자**로 추가
   - B: "사용자 차단(Ban users)" + "초대 링크(Invite users)" 권한 필요
   - A: 관리자이기만 하면 됨 (A 링크를 봇이 만들게 하려면 "초대 링크" 권한)
2. ID 확인: 봇을 넣은 뒤 A 그룹에서 `/id`, B 채널에 `/id` 라고 글 쓰기 → 봇이 ID 답장 (확인 후 글 삭제). 봇 개인 채팅에서 `/id` 하면 내 user id
3. `ADMIN_IDS` 에 본인 user id 입력

## 기존 회원 정리
봇 API 로는 **채널 회원 목록을 볼 수 없음**. 봇은 자기가 켜진 뒤 들어온 사람만 앎.
기존 회원은 아래 중 하나로 목록을 넣어준 뒤 봇에게 `/sweep`:

- **방법 1 (권장)**: `python3 import_members.py` — B 관리자 계정으로 한 번 로그인해서 회원 목록 가져옴
  (my.telegram.org 에서 api_id/api_hash 발급). 끝나면 자동 로그아웃됨.
  채널 특성상 텔레그램이 목록을 일부만 줄 수 있음.
- **방법 2**: user id 가 한 줄씩 적힌 `.txt` 파일을 봇에게 캡션 `/import` 로 보내기

## 관리자 명령 (봇 개인 채팅)
- `/sweep` 지금 바로 전체 정리
- `/stats` 기록된 B 회원 수
- `.txt` 파일 + 캡션 `/import` user id 목록 추가

## 참고
- 봇이 꺼져 있을 때 들어온 입장 요청은 봇이 알 수 없음 → 유저가 다시 요청하거나 봇에게 /start
- 유저가 봇 안내 메시지를 놓쳤으면 봇에게 `/start` 를 보내면 다시 안내받음

## 메시지 문구 바꾸기
유저/관리자에게 보내는 모든 문구와 버튼 이름은 `messages.py` 에 있음. 그 파일만 고치고 봇 재시작.
`{a}` `{b}` 는 A 그룹 / B 채널 이름(자동), `{name}` 은 유저 이름.
